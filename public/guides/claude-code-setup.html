Setting up Claude Code

Everything you need on your laptop before the Saturday morning session, with a button that copies each command so nothing has to be typed by hand.

I am on

No experience is assumed. If you have never opened a terminal, this page is written for you. It takes about 20 minutes, and you only do it once.

The six steps

  1. Install VS Code
  2. Open a terminal
  3. Accept your Claude invitation
  4. Install Claude Code
  5. Check that it worked, and sign in
  6. Open the exercise notebook

First, what these three things are

Three names come up all morning. Here is what each one is, in one sentence.

  • VS Code is a free text editor made by Microsoft. It is a window where you look at the files of a project. You will install it in step 1.
  • A terminal is a window where you type a command, press Enter, and the computer does it. It is already on your machine. You do not install anything for this.
  • Claude Code is the program you are here to learn. It runs inside a terminal, reads the files of your project, and edits them when you ask it to in plain English.

They fit together like this: you open your project folder in VS Code, you open a terminal inside that window, and you start Claude Code in it.

1Install VS Code

A free download from Microsoft. Nothing to configure.

  1. Go to code.visualstudio.com/download and click the Mac download button.
  2. Your browser saves a .zip file. Open your Downloads folder and double-click it. That produces an application called Visual Studio Code.
  3. Drag Visual Studio Code into your Applications folder. This is the step people skip. If you leave it in Downloads it still runs, but it will nag you.
  4. Open it from Applications. The first time, macOS asks whether you are sure you want to open an app downloaded from the internet. Click Open.
  1. Go to code.visualstudio.com/download and click the Windows download button.
  2. Your browser saves a file whose name ends in .exe. Open your Downloads folder and double-click it.
  3. The installer asks a series of questions. Click Next on every screen and accept what is already selected. You do not need to change anything.
  4. Leave Launch Visual Studio Code ticked on the last screen and click Finish.
You can stop worrying about it now VS Code is only a window onto your files. Nothing you do in this guide depends on knowing how to use it beyond opening a folder.

2Open a terminal

A window with a blinking cursor, where you type one line and press Enter.

  1. Press Cmd Space. A search box appears in the middle of the screen.
  2. Type Terminal and press Enter.

A window opens with a line of text and a blinking block after it. That line is the prompt. It is the computer saying it is ready.

  1. Press Win X. A menu appears in the corner.
  2. Choose Windows PowerShell, or Terminal if that is what your menu says.

A window opens with a line of text and a blinking block after it. That line is the prompt. It is the computer saying it is ready.

Windows has two of these, and they are not the same PowerShell and CMD look alike and take different commands. Look at the start of the line. PowerShell begins with PS, as in PS C:\Users\You>. CMD has no PS. You want PowerShell. If you are in CMD, close it and open PowerShell with Win X.

Using a terminal without panicking

  • You type one line and press Enter. Nothing happens until you press Enter.
  • You cannot click on anything inside the window. Use the arrow keys to move around.
  • Text scrolling past is normal. It is the program telling you what it is doing.
  • To paste, press Cmd Vpress Ctrl V, or right-click.
  • Later, once Claude Code is running: Esc interrupts it, and typing exit closes it.

The same terminal, inside VS Code

VS Code has one built in, and that is the one you will use during the exercise. Open your project folder with File, then Open Folder, then open the panel with Terminal, then New Terminal. It is the same program, docked at the bottom of the editor.

3Accept your Claude invitation

Claude Code needs a paid Claude account. The course bought you one.

  1. Look in your mailbox for an email inviting you to join the course's Claude team. Check your spam folder if it is not there.
  2. Click the button in that email and follow it through. You end up with a Claude account that belongs to the course team.
  3. Remember which email address you accepted it with. You will sign in with that address in step 5.
If the invitation never arrived Tell the teaching team at the start of the session. You can follow the whole lecture without it and set the account up afterwards.

4Install Claude Code

One command. Press Copy, paste it into the terminal you opened in step 2, press Enter.

Terminal
$ curl -fsSL https://claude.ai/install.sh | bash

Paste it with Cmd V and press Enter. Text scrolls past for a few seconds. When it finishes you see Claude Code successfully installed!

PowerShell
> irm https://claude.ai/install.ps1 | iex

Paste it with Ctrl V and press Enter. Text scrolls past for a few seconds. When it finishes you see Claude Code successfully installed!

Only if you ended up in CMD The command above is for PowerShell. In CMD, which has no PS at the start of the line, use this one instead.
CMD
> curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

5Check that it worked, and sign in

Two more commands, then a browser window.

First, ask it which version it is. If it answers, it is installed.

Terminal
$ claude --version

2.1.211 (Claude Code)

The number you see will differ. Any number means it worked.

Now start it.

Terminal
$ claude

The first time, it opens a browser window and asks you to sign in. Sign in with the address you accepted the team invitation with, from step 3. Then come back to the terminal. You are done.

If it says command not found, or is not recognized The installer finished, but this terminal window was opened before it did and has not noticed. Close the terminal window and open a new one, then try claude --version again. If it still fails, the fix is in the official installation troubleshooting page, and the teaching team can do it with you in two minutes.

6Open the exercise notebook

The Saturday exercise is a notebook you run on your own machine.

  1. Download it: operation-midnight-launch.ipynb. Your browser saves it to Downloads.
  2. Open VS Code, choose File, then Open File, and pick the file you just downloaded. VS Code opens notebooks itself.
  3. The first time you run a cell, VS Code offers to install the Python extension and to pick a Python installation. Accept both.
  4. Run the first cell. It checks that git, Claude Code and VS Code are all present and tells you if anything is missing.
Why this one is not in Google Colab Every other exercise in this course runs in Colab. This one cannot: Claude Code lives in the terminal of your own laptop and edits files in a folder you own, and Colab has neither. The notebook does the setting up, and Claude Code itself runs in the terminal beside it.
